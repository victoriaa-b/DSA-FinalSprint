# Simple Spring Boot Application

This is a simple Spring Boot application that demonstrates the use of a Binary Search Tree (BST) implemented in Java. 

## Features

- Create binary search trees from input numbers
- - Save and retrieve tree representations
- Create balanced binary search trees using the middle-element approach
- Visualize tree structures in JSON format

  
## Getting Started

Follow these steps to set up the project:

1. **Clone the repository**
   Clone the repository to your local machine using Git:
   git clone <repository-url>

3. **Install dependencies**
Navigate to the project directory and install the required dependencies using Maven:
  cd <project-directory>
  mvn install

3. **Run the Application**
Once the dependencies are installed, you can run the Spring Boot application:
  Run the DemoApplication.java file directly from your IDE

  4. **Access the application**
Once the application is running, open your web browser and visit:
http://localhost:8080/
